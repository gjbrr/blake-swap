Vault

          

            Every record, key and settings value is sealed with a key derived from this
            passphrase before it is stored. The passphrase never leaves this page, and
            losing it loses the records.
          

          
          

            
            
            
          

          

            
            
          

          

            A backup is the whole sealed vault in one file, and the passphrase is its only
            protection. Store it offline: anyone who has the file and the passphrase has
            the vault, and losing the passphrase loses both. Restoring replaces this
            browser's vault, so it also works when the current one will not open.
